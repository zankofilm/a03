# مدرسه‌یار معلم — A10 (آزمون‌ساز بومی؛ پیش‌نویس)

**وضعیت: TEST؛ برای انتشار عملی هنوز تأیید نشده.**

## امکانات افزوده‌شده

- منوی «بیشتر ← ساخت آزمون بومی»؛ همان تم فارسی و آبی‌وسفید، بدون WebView.
- تطبیق درس و کتاب با تخصیص معلم و لیست سؤال‌های تأییدشده مجاز.
- جست‌وجو و انتخاب چند سؤال از کتاب، اعتبارسنجی بارم، عنوان، زمان و تعداد سؤال.
- ثبت **فقط پیش‌نویس** آزمون با API اتمیک `/api/staff/teacher-exams/p673`؛ شناسه پایدار برای پرهیز از ثبت تکراری هنگام تلاش مجدد.
- بازخوانی نمای آزمون‌ها بعد از تأیید ثبت سرور.

## عمداً هنوز انجام نشده

- انتشار و زمان‌بندی رسمی آزمون، ویرایش پیش‌نویس موجود، ایجاد سؤال اختصاصی، بانک سؤال شخصی، تصحیح تشریحی و همه امکانات پنل وب.
- تست واقعی APK با حساب معلم در هاست (ساخت GitHub پس از بارگذاری لازم است).

## مسیر نصب

مخزن فعلی A09: محتوای `INSTALL` بسته پچ را با حفظ مسیر جایگزین کن.

برای تست، از حساب معلم و کلاس آزمایشی استفاده کن؛ ابتدا یک آزمون پیش‌نویس با عنوان متمایز و یک سؤال مجاز بساز؛ در پنل وب ذخیره را تأیید کن.
**دکمه انتشار در A10 وجود ندارد**؛ به دانش‌آموزان اعلان نمی‌رود.

هیچ تغییری در `server.mjs` و دیتابیس هاست وجود ندارد.
