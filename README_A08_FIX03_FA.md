# مدرسه‌یار معلم — A08-FIX03 (تطبیق تخصیص‌های کلاس)

**وضعیت:** نسخه آزمایشی GitHub، هنوز روی گوشی تست نشده است. پایه: A08-FIX02 تأییدشده در تصویر کاربر. این پچ هیچ تغییری در هاست، سرور یا دیتابیس ایجاد نمی‌کند.

## مشکل

کاربر اعلام کرد در پنل وب دو کلاس دارد، اما در اپ اندروید فقط یک کلاس نمایش داده می‌شود. تصویر ارسالی فقط پنل وب را نشان می‌دهد و فهرست داخلی کلاس‌های اندروید را نشان نمی‌دهد؛ در نتیجه بدون پاسخ API نمی‌توان علت قطعی را تعیین کرد. سورس A08-FIX02 از `GET /api/teacher/workspace` استفاده می‌کرد و همه `assignments` برگشتی را نمایش می‌داد، نه فقط یکی را.

## تغییر فنی

- با همان توکن معلم از `GET /api/teacher/workspace` و `GET /api/p635/assignments` استفاده می‌شود. مسیر دوم در سورس موجود سرور فقط **تخصیص‌های فعال همان معلم** را برمی‌گرداند.
- همه ردیف‌های منبع اصلی بدون حذف حفظ می‌شوند. فقط جفت‌های تازه `classId + subject` که از مسیر دوم *با مجوز سرور* برگردند، اضافه می‌شوند. اضافه کردن کلاس از فهرست قدیمی `user.classIds` یا بدون مجوز سرور ممنوع است.
- در «کلاس‌های من» تعداد **کلاس متمایز** جدا از **تخصیص درس** دیده می‌شود؛ به‌علاوه تعداد نتایج گزارش اول و دوم و وضعیت تطبیق.
- اگر هر دو سرویس همان یک کلاس را اعلام کنند، اپ این را به‌عنوان مسئله سروری/تخصیص احتمالی نشان می‌دهد و چیزی را جعل نمی‌کند.
- دفتر نمره، مرکز تکالیف، کارنامه تفصیلی، اثر انگشت، APIهای نوشتن و تم قبلی دست نخورده‌اند؛ همه عملیات همچنان زیر کنترل مجوزهای سرور هستند.
- کد نسخه ۱۴ و نشان A08-FIX03 اضافه شده تا APK قبلی با جدید اشتباه نشود.

## نصب GitHub

برای مخزنی که دقیقاً A08-FIX02 است، **فقط فایل‌های پوشه `INSTALL/` پچ کوچک** را با همان ساختار مسیر در GitHub جایگزین کنید و Commit بزنید. اگر نسخه مخزن نامشخص است، از ZIP کامل در یک مخزن آزمایشی استفاده کنید. پس از موفق‌شدن workflow، APK تازه را از Artifact با نشان `A08-FIX03` بگیرید. فایل‌های بازگشت به FIX02 در پوشه `ROLLBACK_TO_A08_FIX02` بسته کوچک موجودند.

## سناریوی تست

۱. بعد از نصب، در منوی «بیشتر» عبارت A08-FIX03 را ببینید؛ سپس به تب «کلاس‌ها» بروید.

۲. از سرصفحه صفحه «کلاس‌های من» یک عکس بگیرید. اعداد `کلاس`، `تخصیص درس`، `گزارش اصلی` و `گزارش دوم` را بخوانید. رمز، توکن یا اطلاعات خصوصی دانش‌آموزان را نفرستید.

۳. با همان حساب معلم در وب، تعداد و نام کلاس‌های مجاز را مقایسه کنید. اگر کلاس‌های هر دو منبع برابر است ولی وب کلاس بیشتری می‌دهد، وضعیت تخصیص دوم در مدیریت مدرسه (معلم، کلاس، درس، سال تحصیلی، فعال‌بودن و بازه تاریخ) باید بررسی شود.

۴. فقط با داده‌های آزمایشی، ورود به کلاس و گزینه‌های دفتر نمره/تکالیف را بررسی کنید. اگر مسیر API اجازه عملیات ندهد (۴۰۳)، آن را دور نمی‌زنیم.
