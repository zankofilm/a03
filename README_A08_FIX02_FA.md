# مدرسه‌یار معلم — A08-FIX02 / تشخیص نسخه نصب‌شده و دسترسی مرکز تکالیف

**علت محتمل:** اسکرین‌شات کاربر متن A07 را نشان می‌دهد، درحالی‌که A08-FIX01 دکمه «مرکز تکالیف» و متن متفاوت دارد. یعنی APK یا سورس Build شده قدیمی است. این پچ تغییرات را قابل مشاهده و قابل بررسی می‌کند.

- در صفحه «بیشتر» عبارت «نسخه A08-FIX02 · مرکز تکالیف فعال» و گزینه «مرکز تکالیف» در بالای فهرست ظاهر می‌شوند.
- در صفحه «خانه»، یک میان‌بُر مستقیم به مرکز تکالیف افزوده شده است.
- workflow پیش از Build نسخه سورس را کنترل می‌کند و اگر فایل‌های قدیمی مخلوط شده باشند خطا می‌دهد.
- versionCode برابر ۱۳ است و خروجی GitHub Actions با شماره اجرای همان Build نام‌گذاری می‌شود.
- هیچ تغییری به سرور، دیتابیس، مدیریت اولیا، اثر انگشت، دفتر نمره و منطق ثبت/تصحیح تکلیف داده نشده است.

## نصب روی GitHub

اگر مخزن GitHub دقیقاً A08-FIX01 است، ۴ فایل پوشه INSTALL را در مسیر مشابه جایگزین کنید (فایل verify_a08_menu.py فایل جدید است). Commit و سپس Actions را اجرا کنید. در صورت وجود شک نسبت به نسخه فعلی مخزن، به‌جای Patch، ZIP کامل را در یک مخزن آزمایشی تازه قرار دهید.

بعد از ساخت، نام Artifact باید شامل A08-FIX02 باشد. بعد از نصب، در صفحه «بیشتر» عبارت نسخه A08-FIX02 دیده شود و اولین گزینه «مرکز تکالیف» باشد. اگر عبارت دیده نشد، APK قدیمی اجرا می‌شود. در این صورت زمان آخرین اجرا و فایل دانلودشده را کنترل کنید؛ نصب نسخه Debug با امضای متفاوت ممکن است به حذف نسخه قبلی نیاز داشته باشد. پیش از حذف، اطلاعات محلی برنامه مانند تنظیم اثر انگشت حذف می‌شود؛ اطلاعات اصلی مدرسه روی سرور حفظ می‌مانند.

تست ایستا و قواعد Java با ابزارهای موجود انجام شده‌اند؛ **ساخت APK واقعی یا تست گوشی در محیط بسته انجام نشده است.**
