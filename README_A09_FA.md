# مدرسه‌یار معلم — A09 آزمایشی | کتابخانه رسمی سؤال‌های تأییدشده

این بسته از A08-FIX04 ساخته شده است. تمام صفحه‌ها و فرم‌های A08-FIX04، ورود فارسی و بومی، دفتر نمره، کارنامه تفصیلی، مرکز تکالیف، هماهنگ‌سازی کلاس و بازیابی امن ورود با اثر انگشت حفظ شده‌اند.

## قابلیت تازه
«بیشتر ← کتابخانه سؤال‌های تأییدشده» با رابط بومی اندروید و بدون WebView. فقط سؤال‌های مورد تأیید مدیریت مدرسه که سرور به معلم فعلی اجازه دیدنشان را می‌دهد از `GET /api/staff/teacher-approved-questions/p67` دریافت می‌شود. نمایش فهرست کتاب‌های مجاز، فیلتر کتاب، جست‌وجوی متن، صفحه‌بندی ۳۰تایی، نوع و دشواری، بارم، تعداد استفاده قبلی معلم، گزینه‌ها، پاسخ صحیح، پاسخ تشریحی و توضیح سؤال پیاده شده است.

**فقط خواندنی:** این نسخه از بانک رسمی سؤال چیزی حذف، ویرایش یا کپی نمی‌کند. مدیریت بانک سؤال شخصی، ساخت/انتشار آزمون، تصحیح تشریحی و گزارش‌های باقیمانده هنوز کامل نشده‌اند و نباید تکمیل‌شده تلقی شوند.

## نصب و آزمون
1. در مخزن **A08-FIX04**، فقط محتویات `INSTALL` از بسته کوچک را با مسیر فایل‌ها جایگزین و Commit کنید؛ یا محتویات پروژه کامل را در مخزن آزمایشی جداگانه بارگذاری کنید.
2. GitHub → Actions → Build Native Teacher Android APK. خروجی آزمایشی باید عنوان A09 داشته باشد.
3. وارد حساب آزمایشی معلم شوید؛ «بیشتر ← کتابخانه سؤال‌های تأییدشده» را باز کنید.
4. با کتاب و کلمات متفاوت جست‌وجو کنید و سؤال‌ها، گزینه‌ها و پاسخ‌ها را با پنل وب و مجوز همان معلم مقایسه کنید. سؤال‌های فاقد مجوز نباید نمایش داده شوند.
5. برای تثبیت A09، حضور، نمره، تکالیف، کارنامه تفصیلی و اثر انگشت را نیز به‌صورت تکرارپذیر بررسی کنید.

**وضعیت QA:** تست‌های ساختاری و قواعد Java روی سورس اجرا می‌شوند. ساخت کامل APK، تست روی گوشی، عملکرد API سرور زنده و تست امنیت دسترسی هنوز تأیید نشده‌اند. هیچ تغییری در سرور/دیتابیس/نسخه مادر لازم نیست.

**بازگشت:** پوشه `ROLLBACK_A08_FIX04` در پچ کوچک، فایل‌های پیشین را دارد.
