# مدرسه‌یار معلم — A10.1 (آزمون مستمر و پایان‌ترم از مخزن سؤال)

**وضعیت: TEST؛ APK هنوز روی GitHub و گوشی آزمایش نشده است.**

## تفاوت با A10
- انتخاب صریح «آزمون مستمر» یا «آزمون پایان‌ترم» در همان فرم بومی اندروید.
- انتخاب نیم‌سال اول یا دوم؛ ارسال واقعی examCategory و academicPeriod به سرور.
- انتخاب سؤال از **مخزن رسمی تأییدشده** معلم (`GET /api/staff/teacher-approved-questions/p67`)؛ فیلتر کتاب/درس/کلاس، متن، فصل، نوع تستی/تشریحی و دشواری. شناسه منبع سؤال حفظ می‌شود.
- آزمون مستمر: بارم اصل سؤال‌ها بدون دست‌کاری حفظ می‌شود.
- آزمون پایان‌ترم: سهم مستمر از `GET /api/staff/gradebook` دریافت و سقف پایانی برابر با `۲۰ منهای سهم مستمر` محاسبه می‌شود. اگر جمع بارم‌های انتخابی متفاوت باشد، در صورت امکان به گام‌های یک‌چهارم نمره بازتوزیع شده و **قبل از ذخیره به معلم اطلاع داده می‌شود**. اگر تقسیم معتبر نباشد ذخیره مسدود می‌شود. سرور همچنان مرجع قطعی کنترل بارم و دسترسی است.
- تنها پیش‌نویس آزمون با `POST /api/staff/teacher-exams/p673` ذخیره می‌شود. هیچ اعلان یا انتشار خودکاری انجام نمی‌شود.
- آیکون، تم آبی‌وسفید، زبان فارسی، اثر انگشت، دفتر نمره، کارنامه تفصیلی و تکالیف حفظ شده‌اند.

## روش نصب
- اگر GitHub روی **A10** است: فقط محتویات `INSTALL` از بسته Patch را جایگزین و Commit کنید؛ فایل جدید ExamCategoryRules.java و ابزارهای تست را فراموش نکنید.
- اگر مخزن روی نسخه قدیمی‌تر است: **پروژه کامل ZIP** را در مخزن آزمایشی جداگانه قرار دهید.
- سپس Actions > Build Native Teacher Android APK را اجرا و APK آزمایشی را از Artifacts دریافت کنید.
- برای برگشت از `ROLLBACK_TO_A10` استفاده کنید؛ فایل جدید ExamCategoryRules.java را هنگام بازگشت حذف کنید.

## سناریوی تست واقعی
۱. با معلم آزمایشی وارد شوید؛ یک کلاس مجاز، کتاب و چند سؤال تأییدشده انتخاب کنید.
۲. آزمون **مستمر نیم‌سال اول** را فقط پیش‌نویس کنید؛ در پنل وب نوع، نیم‌سال و سؤال‌های منبع را بررسی کنید.
۳. آزمون **پایان‌ترم نیم‌سال دوم** بسازید؛ سقف بارم را با دفتر نمره وب مقایسه کنید و پس از تأیید پیش‌نویس، ذخیره سرور را بررسی کنید.
۴. فیلترهای فصل، دشواری، تستی و تشریحی را تست کنید؛ انتخاب سؤال پس از جست‌وجو باقی بماند.
۵. هیچ‌یک نباید برای دانش‌آموز منتشر یا اعلان شوند.

## محدودیت‌ها
- فعلاً فقط بانک **رسمی تأییدشده** قابل انتخاب است؛ بانک سؤال شخصی معلم هنوز در این سازنده ادغام نشده است.
- زمان‌بندی و انتشار، ویرایش پیش‌نویس موجود، آزمون‌ساز هوشمند، چاپ برگه آزمون و تصحیح کامل هنوز در این نسخه ایجاد نشده‌اند.
- API دفتر نمره ممکن است برای معلمی که مجوز دفتر نمره ندارد، قابل دسترسی نباشد. در این حالت ذخیره پایان‌ترم متوقف می‌شود؛ مجوز را با مدیر بررسی کنید.
- ممکن است سیاست قدیمی termPolicies با تنظیم جدید gradebookConfigs متفاوت باشد. خطای معتبر سرور در این حالت مانع ثبت می‌شود و باید پیکربندی وب بررسی شود.
- هیچ تغییر روی هاست، server.mjs یا دیتابیس وجود ندارد. نسخه مادر پروژه تغییر نکرده است.
